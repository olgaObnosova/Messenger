# 📱 Мессенджер на Node.js (Express + Socket.IO + SQLite)

**Версия:** 1.0  
**Дата последнего обновления:** 2026  
**Автор:** Ваше имя

Полнофункциональный веб-мессенджер с общим чатом, приватными сообщениями, отправкой файлов (изображения, документы), голосовыми сообщениями и статусом «онлайн».  
Проект построен на **Node.js + Express** (backend), **Socket.IO** (real‑time), **SQLite** (БД) и чистом **HTML/CSS/JS** (frontend).

## ✨ Возможности

- **Аутентификация** – регистрация и вход с хешированием паролей (bcryptjs).
- **Общий чат** – все сообщения видны всем авторизованным пользователям.
- **Приватные сообщения** – личные переписки между двумя пользователями.
- **Отправка файлов** – изображения (просмотр в чате) и любые документы (архивы, PDF, текстовые файлы) до 50 МБ.
- **Голосовые сообщения** – запись через микрофон прямо в браузере (до 10 секунд, формат WebM).
- **Аватары** – выбор emoji в качестве аватара, обновление в реальном времени для всех.
- **Статус «онлайн»** – отображение пользователей в сети и времени последнего визита.
- **Индикатор «печатает»** – в общем чате: отображается, кто в данный момент набирает текст.
- **Уведомления о новых сообщениях** – в приватных чатах: визуальное выделение непрочитанных сообщений.
- **Сохранение истории** – последние 200 сообщений в общем чате и 200 на каждого собеседника в приватных.
- **Автоматическое создание базы данных** – SQLite создаёт файл `messenger.db` при первом запуске.

## 📋 Требования

- **Node.js** версии 12.x или выше (рекомендуется 16+)
- **npm** (обычно устанавливается вместе с Node.js)
- **Современный браузер** с поддержкой:
  - WebSocket (Socket.IO)
  - MediaRecorder API (для голосовых сообщений)
  - Fetch API, FormData
- **Свободный порт** 3000 (или любой другой, который укажете)
